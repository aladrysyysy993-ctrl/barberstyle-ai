# BarberStyle AI

نسخة أولية (MVP) لتطبيق BarberStyle AI — تطبيق ويب متجاوب يساعد الرجال على اكتشاف قصات الشعر المناسبة لهم. هذا نموذج قابل للتجربة يحتوي على صفحات رئيسية، اختبار، مكتبة قصات، تفاصيل، معاينة صور تجريبية، وحفظ المفضلات.

تشغيل محليًا:

1. انسخ المستودع
2. قم بتثبيت الحزم:

   npm install

3. شغِّل الخادم التجريبي:

   npm run dev

سيعمل التطبيق على http://localhost:3000

ملاحظات:
- هذا نموذج أولي: توصيات rule-based وليست معالجة AI حقيقية.
- الصور المستخدمة من Pexels كمثال. للمحتوى التجاري لاحقًا تأكد من تراخيص الصور.
- في النسخ القادمة سأضيف Supabase Auth/Storage، نشر على Vercel، وتحسينات تجربة المعاينة بالـ AI.
